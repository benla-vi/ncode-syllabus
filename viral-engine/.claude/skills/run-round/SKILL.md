# /run-round — ראונד המחקר היומי

אתה **המתזמר**. אתה מתכנן ושולח סוכנים, לא כותב תוכן בעצמך.
המטרה: להפיק **תפריט סיפורים** מדורג ולפרסם אותו כדף Artifact — ואז לעצור.
**אסור לכתוב תסריט אחד** בראונד הזה — זה שלב `/write-scripts` בלבד, ורק אחרי שבעל-הבית אומר מספרים.

קרא את `CLAUDE.md` (נטען אוטומטית) ואת `docs/GLOSSARY.md` אם לא קראת עדיין.

---

## פיצול מודלים (קדוש)
- **סקאוט + מיזוג + דירוג = Sonnet.** כל השלבים כאן מהירים/מכניים.
- אין Opus בראונד הזה — Opus שמור לכתיבה/ביקורת ב-`/write-scripts`.

---

## שלב 0 — הכנה
1. `git pull` על main כדי לקבל שיפורים של משתפי-פעולה אחרים.
2. קבע `date = היום` (YYYY-MM-DD). כל הפלטים ל-`output/<date>/`.
3. טען `config.yaml` — ממנו העדשות: `news.x_accounts`, `news.trend_sources`, `news.research_channels`, `news.topics`.

## שלב 1 — סקאוט מקבילי (עדשות, Sonnet)
- שגר **כמה סוכני Agent במקביל** (בהודעה אחת), עדשה לכל אחד — לפי `prompts/01-news-scout.md`:
  - עדשה חדשות/טרנדים (X + ניוזלטרים + HN/Reddit)
  - עדשה אאוטליירים (דפי-הייחוס מ-`research_channels`, חילוץ **פורמט** מוכח בלבד)
  - עדשה wealth/סיפור-דמות (אופציונלי, כשיש חזק)
- כל סוכן: `model: sonnet`, מונחה ב-`prompts/01-news-scout.md`, מחזיר JSON של סיפורים **Tier-tagged** (כל עובדה עם מקור + Tier).
- הדגש בהוראה: **חוק ההתכנסות** (כל סיפור מגשר ל"בונים אפליקציה עם AI"), Tier-tagging חובה.

## שלב 2 — מיזוג + דה-דופ (מכני, בסשן)
- אחד את פלטי כל הסקאוטים לרשימה אחת.
- הסר כפילויות (אותו סיפור משתי עדשות) — שמור את הגרסה העשירה יותר.
- מספר מחדש `id` רץ. שמור ל-`output/<date>/01-stories.json`.

## שלב 3 — דירוג (סוכן Sonnet)
- שגר סוכן מדרג לפי `prompts/02-virality-scorer.md` על כל הסיפורים.
- `model: sonnet`. מחזיר `ranking` (כל הסיפורים, ממוינים) + `recommended_ids`.
- **שום דבר לא נפסל** — המדרג ממליץ, בעל-הבית בוחר. שמור ל-`output/<date>/02-ranking.json`.

## שלב 4 — רינדור התפריט
```
python pipeline/render_gdoc_html.py <date> --menu
```
מייצר `output/<date>/menu.html` (RTL, מודגש, ⭐ להמלצות).

## שלב 5 — פרסום כ-Artifact
- פרסם את `output/<date>/menu.html` בכלי **Artifact** (favicon למשל 🎬, title "תפריט סיפורים <date>").
- הדף כבר RTL ומותאם דיסלקציה — אל תעטוף בקירות טקסט נוספים.
- **אסור להגיש קובץ להורדה. אסור ClickUp.** רק לינק ה-Artifact.

## שלב 6 — קומיט + מסירה
- `git add output/<date>` וקומיט ("ראונד <date>").
- מסור לבעל-הבית את **לינק ה-Artifact** בלבד, וסיים ב:

> **תגיד לי מספרים לכתיבה** (למשל: "7, 11, 16") — ואז נריץ `/write-scripts`.

**עצור כאן.** אל תתחיל לכתוב עד שיש מספרים.
