# 🎬 viral-engine — מנוע התוכן הוויראלי

**הריפו הזה הוא הסוכן.** פותחים עליו סשן Claude Code — וזה מנוע התוכן, מוכן לעבודה.
מערכת סוכני AI מקצה לקצה שמייצרת יומית תסריטי סרטונים ויראליים ("לעשות כסף עם AI
דרך בניית אפליקציות"), בקול של בן, לקהל בהלת-הזהב הישראלי.

## התחלה מהירה (למשתפי-פעולה)
1. **פתח סשן Claude Code על הריפו הזה.** `CLAUDE.md` נטען אוטומטית — הוא מדריך
   התפעול המלא, וזה כל מה שסשן חדש צריך כדי להפעיל את הסוכן נכון. קרא אותו קודם.
2. הרץ **`/run-round`** — מחקר יומי → תפריט סיפורים כדף Artifact.
3. אמור מספרים בצ'אט (הסיפורים שבחרת) → **`/write-scripts 7,11,16`** → תסריטים
   מוכני-צילום כדף Artifact.

> הסשן הוא **מתזמר בלבד**: מתכנן ושולח סוכנים. כתיבה/ביקורת = Opus, מחקר/מכניקה =
> Sonnet. הכללים המלאים ב-`CLAUDE.md`. להעברה לריפו עצמאי: `MIGRATION.md`.

מה מיוצר יומית:
- **תסריטים לסרטונים אורגניים** בפורמט "חדשות → סיפור → ערך → שער תגובות"
- **קריאייטיבים לקמפיינים ממומנים** בסגנון סרטוני המכירה
- כולל: הוקים (5 וריאציות), מילת תגובה, מתנה, נוסח DM, קפשן, והמשך פאנל

## איך זה עובד

```
🔍 סוכן 1: סקאוט         סורק X/חדשות/רדיט עם חיפוש רשת, מביא 10 סיפורים
        ▼
⚖️ סוכן 2: שופט ויראליות   מדרג לפי STEPPS + רלוונטיות, בוחר 3
        ▼
✍️ סוכן 3: תסריטאי         כותב תסריט מלא בסגנון שלך (לפי מדריך הסגנון)
        ▼
🧐 סוכן 4: מבקר            עורך קשוח: הוק, ריטנשן, שפה, עובדות, פאנל
        ▼
📄 בריף יומי               output/YYYY-MM-DD/brief.md — מוכן לצילום
```

## התקנה (פעם אחת)

```bash
cd viral-engine
pip install -r pipeline/requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
```

ואז ערוך את `config.yaml`: הלינקים לפאנלים שלך (יוטיוב, וובינר Base44, קורסים),
ההנדל שלך, והמתנות החינמיות. יש TODO בכל מקום שדורש עדכון.

## שלב 0 (חשוב!): למידת הסגנון

המערכת לומדת לכתוב כמוך וכמו טל מתמלולים. הסביבה הזאת (הריצה בענן) חסומה
לגישה לאינסטגרם/טיקטוק ולהורדת מודלים — לכן התמלול חייב לרוץ **במחשב שלך**.

**דרך מהירה: `pipeline/local_transcribe.py`** — סקריפט שמוריד + מתמלל בפקודה אחת
(רץ **אצלך**, לא כאן):

```bash
pip install yt-dlp openai-whisper

# הסרטון שלך (250K צפיות)
python pipeline/local_transcribe.py --category ben \
    --url "https://www.instagram.com/reels/DPlQ-5tiIY2/"

# כמה סרטונים של טל
python pipeline/local_transcribe.py --category tal \
    --url "https://www.instagram.com/reel/XXXXX/" \
    --url "https://www.instagram.com/reel/YYYYY/"

# סרטוני המכירה מהוואטסאפ (קובץ מקומי, לא URL)
python pipeline/local_transcribe.py --category ads --file ~/Downloads/tal-ad-1.mp4
python pipeline/local_transcribe.py --category ads --file ~/Downloads/tal-ad-2.mp4
```

זה שומר קבצי `.txt` ישר ב-`knowledge/transcripts/<category>/` — בדיוק במבנה
שהמערכת מצפה לו. אחרי שיש קבצים, תעלה/י את התוכן שלהם לצ'אט (או Push לגיט),
ואז תריצי כאן:

**דרך חלופית ללא התקנות:** מעתיקים את הכתוביות האוטומטיות של הריל/טיקטוק
(כפתור CC בסרטון) ומדביקים לי ישירות בצ'אט — אני אשמור בקובץ הנכון.

ואז, בכל מקרה:
```bash
python pipeline/ingest_style.py
```
זה יוצר את `knowledge/style/style-organic.md` ו-`style-ads.md` — מדריכי סגנון
שכל הסוכנים משתמשים בהם מעכשיו. (בלי זה המערכת עובדת, אבל בסגנון כללי.)

## שימוש יומי

```bash
# הריצה היומית המלאה (חדשות → 3 תסריטים מוכנים)
python pipeline/run_daily.py

# יש לך כבר סיפור? דלג על הסקאוט:
python pipeline/run_daily.py --story "ילד בן 12 מסינגפור בנה אפליקציה ש..."

# קריאייטיבים לממומן (לפי id של פאנל מ-config.yaml)
python pipeline/make_ads.py --offer base44_webinar
python pipeline/make_ads.py --offer-text "הצעה חופשית..." --num 5
```

## מה יש בתיקייה

| נתיב | מה זה |
|---|---|
| `config.yaml` | ההגדרות שלך: פאנלים, מתנות, מילות טריגר, מקורות חדשות |
| `prompts/` | הפרומפטים של כל סוכן — זה ה-IP. ערוך אותם כדי לכוונן התנהגות |
| `pipeline/` | הקוד: `run_daily.py`, `make_ads.py`, `ingest_style.py` |
| `knowledge/transcripts/` | אזור ההזנה — שים כאן תמלולים |
| `knowledge/style/` | מדריכי הסגנון שנוצרים אוטומטית |
| `docs/PLAYBOOK.md` | **חובה לקרוא** — כל מדע התוכן הוויראלי, מבוסס מחקר עם מקורות |
| `docs/FUNNEL.md` | מכניקת שער התגובות וה-ManyChat, מהתגובה ועד הלקוח המשלם |
| `output/` | הבריפים היומיים |

## הצעד הבא אחרי הסקריפט: ManyChat
כל בריף כולל מילת תגובה + נוסח DM. צריך להגדיר ב-ManyChat (Pro, ~$29/חודש):
טריגר תגובה על הפוסט → DM עם כפתור → מסירת מתנה → איסוף אימייל → סנכרון ל-ESP.
המדריך המלא: `docs/FUNNEL.md`.

## שדרוגים עתידיים (לא ממומשים עדיין)
- **חיבור ישיר ל-X** דרך twitterapi.io (~$50-150/חודש) במקום חיפוש רשת — מהיר וטרי יותר
- **ריצה אוטומטית יומית** עם GitHub Actions + שליחת הבריף לוואטסאפ/מייל
- **תמלול אוטומטי** של סרטונים חדשים של מתחרים ועדכון מדריך הסגנון

## עדכון יולי 2026 — ClickUp, נרטיב הזהב, וידע מותג

- **מערכת ניהול ב-ClickUp:** כל סיפור מהריצה היומית נכנס כמשימה (סטטוסים: 📥 תפריט → ✅ אישרתי → ✍️ בכתיבה → 📝 תסריט מוכן → 🎥 צולם → 🚀 פורסם). בן מאשר בגרירה; כתיבת תסריטים מתחילה רק בהוראה בצ'אט. פירוט מלא: `docs/CLICKUP-WORKFLOW.md`. שכבת התרגום: `pipeline/clickup_export.py`. אין יותר גוגל דוקס בזרימה השוטפת.
- **נרטיב ברירת-מחדל — "בהלת הזהב של ה-AI":** כל השרשרת (סקאוט→שופט→תסריטאי→מבקר) מוזרקת ב-`knowledge/brand/ncode.md` (מי אנחנו) ו-`knowledge/audience/ai-goldrush.md` (למי מדברים). גשר הערך תמיד: "איך אתה מרוויח מזה". חומרי הגלם: `knowledge/research/`.
- **דאטהבייס:** `output/<date>/` מקומט לגיט בכוונה (`git add -f`) — זה התיעוד הקנוני של כל ריצה; ClickUp הוא שכבת ה-state.

### העברה עתידית לפרויקט "המוח השני"
התיקייה `viral-engine/` עצמאית לחלוטין. כדי להעביר לרפו אחר: פתחו סשן Claude Code על הרפו השני → העתיקו את התיקייה מהענף הזה → קומיט. הדוקים בדרייב ורשימת ה-ClickUp לא תלויים ברפו ולא מושפעים מהמעבר.
