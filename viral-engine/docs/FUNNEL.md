# מפת המשפך: מתגובה ללקוח משלם

> מכניקת ManyChat המלאה + בנצ'מרקים, מבוסס מחקר יולי 2026.
> הערה: רוב המספרים מפורסמים ע"י ספקי האוטומציה עצמם — התייחס אליהם כגבול עליון אופטימי.

## המשפך המלא

```
ריל ויראלי (הוק → סיפור → ערך)
        │  "תגיבו 'כלים' ואני שולח לכם את הרשימה"
        ▼
תגובה במילת הטריגר
        │  ManyChat: תגובה פומבית ("שלחתי! תבדוק DM 📩")
        ▼
DM ראשון — עם כפתור, לא לינק!  ← קריטי: הקשה על הכפתור פותחת חלון 24 שעות
        │  (אופציונלי: בדיקת עוקב — "עקוב קודם ואז לחץ")
        ▼
מסירת המתנה מיד + בקשת אימייל (Data Collection block)
        │  30-50% נותנים אימייל; הצעות חזקות מגיעות ל-70-85%
        ▼
סנכרון ל-ESP (אינטגרציה ישירה: Kit/ActiveCampaign/Mailchimp/Klaviyo)
        │
        ▼
2-4 הודעות המשך בתוך חלון ה-24 שעות
        │  (תזכורת להוריד → הוכחה חברתית → הזמנה לצעד הבא)
        ▼
הצעד הבא בפאנל לפי סוג הסרטון:
  ├── יוטיוב / הדרכה חינמית  (קהל קר — בניית אמון)
  ├── קורס חינמי             (קהל פושר — איסוף מחויבות)
  ├── וובינר Base44           (קהל שראה סיפור על בניית אפליקציות)
  └── הקורס בתשלום           (רק לקהל חם / רימרקטינג / אימייל)
```

## חוקי הפלטפורמה שמעצבים הכל
- **חלון 24 שעות:** מותר לשלוח הודעות רק תוך 24 שעות מהאינטראקציה האחרונה. כל תגובה של המשתמש מאפסת את השעון.
- **אין התראות מחוץ לחלון באינסטגרם** (OTN קיים רק במסנג'ר) ⇒ **האימייל הוא נכס ההמשך היחיד שלך.** בלי איסוף אימייל — הליד מת אחרי 24 שעות.
- **מגבלת קצב:** ~200 DM אוטומטיים לשעה. סרטון ויראלי באמת יעבור את זה — ManyChat מטפל בתור.
- **ManyChat מתומחר לפי אנשי קשר פעילים** (Pro $29/חודש עד 2,500): ריל ויראלי = קפיצה בחשבון. לתכנן מראש.

## מה ממיר הכי טוב (לפי הצלחות מתועדות)
| מתנה | מתי | דוגמה מהמחקר |
|---|---|---|
| צ'קליסט / PDF | ברירת מחדל — קל לצרוך | ManyChat שולח PDF ישירות ב-DM |
| חבילת פרומפטים / טמפלטים | הפורמט החם בנישת AI | "Comment 'Claude' → the prompts" |
| קוויז | סגמנטציה + התאמה אישית | ג'נה קוצ'ר — 38-52K אימיילים בשנה |
| סדנה / וובינר חינמי | הכי הרבה הכנסה בהמשך | איימי פורטרפילד: 2,650 לידים → 924 רכישות → $1.4M מפוסט אורגני |

**העיקרון החזק ביותר במחקר:** מתנה ספציפית-לסרטון ממירה פי 3.1 ממתנה גנרית אחת לכל הסרטונים.

## בנצ'מרקים (זהירות: מקורות של ספקים)
- פתיחת DM: 70-90% בשעה הראשונה (לעומת ~20% באימייל)
- קליק על לינק ב-DM: ~28% (לעומת 2-3% באימייל)
- מגיבים → נרשמים בתשלום: 5-8% במשפך בנוי טוב
- חשבונות 10-100K עוקבים ממירים *יותר טוב* מחשבונות ענק (15-20% לעומת 7-12% קליק→רכישה)

## נוסח DM מומלץ (התבנית שהסוכן משתמש בה)
```
הודעה 1 (מיד): "הנה מה שהבטחתי 🎁 [כפתור: קח אותי לזה]"
הודעה 2 (אחרי הקשה): המתנה עצמה + "רוצה שאשלח לך גם את [הצעד הבא]? תשאיר אימייל ואני שולח"
הודעה 3 (אחרי אימייל): לינק לצעד הבא בפאנל + משפט אחד למה שווה
```
כלל: לתת קודם, לבקש אחר כך. הודעה ראשונה בלי לינק גולמי (נראה ספאמי ולא פותח חלון).

## ממומן — הבדל קריטי
שער תגובות **לא עובד על מודעות דארק-פוסט באינסטגרם** (Ads Manager) — האוטומציה לא
נתפסת שם. אפשרויות: (א) לקדם פוסט קיים דרך Boost בתוך האפליקציה — שם האוטומציה כן
עובדת; (ב) מודעות Click-to-Message; (ג) בפייסבוק זה כן נתמך. את הקריאייטיבים לממומן
בונים עם CTA של קליק (ראה `prompts/04-ad-writer.md`).

## מדדים לניטור שבועי
1. תגובות ÷ צפיות (יעד: 1%+ בסרטון עם שער)
2. תגובה → DM נפתח → אימייל נמסר (כל שלב)
3. אימייל → הגעה לצעד הבא בפאנל (צפייה ביוטיוב / רישום וובינר)
4. עלות ManyChat ÷ לידים חדשים
