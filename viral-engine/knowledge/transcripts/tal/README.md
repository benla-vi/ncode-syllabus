# תמלולים — טל רוטר (אורגני)

שים כאן קבצי `.txt` / `.md` עם תמלולים של סרטונים ויראליים של טל.
קובץ אחד לכל סרטון. פורמט מומלץ בראש הקובץ:

```
צפיות: 250000
פלטפורמה: אינסטגרם
לינק: https://...
---
(התמלול המלא כאן, מילה במילה)
```

איך משיגים תמלול: מורידים את הסרטון ומתמללים עם Whisper:
`whisper video.mp4 --language he --model large-v3`
