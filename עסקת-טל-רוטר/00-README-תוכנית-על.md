## תקציר העסקה (כפי שהבנתי — נא לאשר)

- **הצד השני:** טל רוטר. מכללה בתחומי דרופשיפינג, איקומרס ו-AI. שותפים נוספים: שלו אפרח (השותף השלישי).
- **מהות:** N-code לוקחת את **מוקד המכירות** שלהם כ-**אאוטסורס**.
- **תמחור:** **33% מהמחזור, כולל מע"מ**, מחושב מהמחיר הכולל מע"מ ללקוח.
  - דוגמה: מכירה ב-11,900 ₪ (כולל מע"מ) → חלק N-code = 3,927 ₪ כולל מע"מ → נטו ל-N-code ≈ 3,328 ₪ (לפי מע"מ 18%).
- **התחייבות:** מינימום 3 חודשים (לדעתכם — לא מספיק; ראו מסמך 03).
- **ווליום:** ~500 לידים/חודש, מתוכם ~300 זומים שנקבעים אצל טל היום.
- **רכיב שני בעסקה:** פיתוח מערכת **CRM** חדשה (ה-CRM הקיים שלהם גרוע).

## רשימת משימות-על (Action Items)

סטטוס: ⬜ פתוח | 🔵 בתהליך | ✅ הושלם

### החלטות פנימיות (שותפי N-code)
- ⬜ להחליט על **מבנה תגמול הנציגים** למוצר הזה (מסמך 04)
- ⬜ להחליט **צוות ייעודי מול צוות משותף** עם N-code, כדי שלא תהיה פגיעה במוצר העיקרי (מסמך 01 + 04)
- ⬜ לאשר את **מודל הקיבולת והגיוס** (כמה נציגים, אילו תפקידים) (מסמך 05)
- ⬜ לגבש את **רשימת סעיפי ההגנה** הסופית להסכם (מסמך 03)

### מול UNI
- ⬜ **לשבת עם UNI** ולבדוק פערים במודל הכלכלי — בסיס העמלה, החזרים, גבייה, מע"מ, רווחיות יחידה (מסמך 02)

### מול שלו אפרח (השותף השלישי)
- ⬜ **לקבוע שיחה עם שלו אפרח** ולעבור על: בלעדיות, התחייבות לכמות/איכות לידים, מנגנון סיום, בעלות על דאטה (מסמך 03)

### מול טל רוטר
- ⬜ לשלוח לטל את **בקשת הדאטה / "ספר העסק"** המלאה (מסמך 06)
- ⬜ לבקש במפורש את **סיפורי ההצלחה והסטודנטים המוצלחים** (חלק ממסמך 06)
- ⬜ לקבל **גישה ל-CRM הקיים, פאנלים, מנהל מודעות, חשבון סליקה** (מסמך 06 + 07)

### פרויקט CRM (אספקה: דניאל זכות כפרילנסר + KD Tech / יובל כידר)
- ⬜ לקיים **שיחת Discovery** ולמפות דרישות לפני שנותנים מחיר (מסמך 07)
- ⬜ להחליט **build מול configure** (מערכת קיימת מותאמת — להעריך GoHighLevel) (מסמך 07)
- ⬜ לסגור **הסכם פרילנס + IP + NDA** מול דניאל, עם **תיעוד וחפיפה ל-KD** כתנאי לתשלום (מסמך 07)
- ⬜ להגדיר **גבולות גזרה דניאל↔KD** ומודל תחזוקה שוטף ל-KD (מסמך 07)
- ⬜ לאמת ש-**25K מכסה את הסקופ** ולמקם את הפרויקט כמנוף לעסקת המוקד (מסמך 07)

## איך מתקדמים מכאן (סדר מומלץ)

1. **שבוע 1:** שיחה פנימית של השותפים → אישור מבנה תגמול + צוות + סעיפי הגנה. במקביל — לשלוח לטל את בקשת הדאטה (מסמך 06).
2. **שבוע 1–2:** ישיבה עם UNI על המודל הכלכלי (מסמך 02). שיחה עם שלו אפרח על ההגנות (מסמך 03).
3. **שבוע 2:** קבלת הדאטה מטל + Discovery ל-CRM.
4. **שבוע 2–3:** סגירת ההסכם המסחרי + ההסכם על ה-CRM.
5. **שבוע 3–6:** גיוס והכשרת נציגים (שבוע הכשרה לפי ספר העסק) + הקמת MVP של ה-CRM.
6. **שבוע 6+:** Go-live הדרגתי + אופטימיזציה.
